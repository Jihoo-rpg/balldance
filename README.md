# balldance · 쌍성 궤도

두 행성이 번갈아 서로를 돌며 길을 따라가는 리듬 게임입니다. 도는 행성이 다음 칸에 닿는 순간 박자에 맞춰 누르세요.

브라우저에서 `balldance.html`을 열면 바로 플레이할 수 있어요. 설치할 것도, 외부 음원도 없이 음악은 Web Audio로 직접 만들어집니다.

## 조작
- 아무 키 / 화면 탭: 누르기
- `Esc`: 그만두기
- `R` 또는 `Space`: 결과 화면에서 다시 하기

## 규칙
- 직선은 1박자, 왼쪽으로 꺾으면 짧게, 오른쪽으로 꺾으면 길게 돕니다.
- 회전 표시 칸에서는 도는 방향이 반대로 바뀝니다.
- `×1.5`, `×2` 칸부터 빨라지고 `×1`에서 원래 속도로 돌아옵니다.
- 판정: 완벽 / 빠름 / 느림 / 놓침. 놓치면 실패 (연습 모드에서는 계속 진행).
- 깃발 칸은 체크포인트예요. 실패하면 마지막으로 지난 깃발부터 다시 할 수 있어요 (Space).
