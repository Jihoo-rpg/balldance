# balldance · 쌍성 궤도

두 행성이 번갈아 서로를 돌며 길을 따라가는 리듬 게임입니다. 도는 행성이 다음 칸에 닿는 순간 박자에 맞춰 누르세요.

브라우저에서 `balldance.html`을 열면 바로 플레이할 수 있어요. 설치할 것도, 외부 음원도 없이 음악은 Web Audio로 직접 만들어집니다.

## 조작
- 아무 키 / 화면 탭: 누르기
- `Esc`: 그만두기
- `R` 또는 `Space`: 결과 화면에서 다시 하기

## 규칙
- 직선은 1박자, 왼쪽으로 꺾으면 짧게, 오른쪽으로 꺾으면 길게 돕니다.
- 회전 표시 칸에서는 도는 방향이 반대로 바뀝니다.
- `×1.5`, `×2` 칸부터 빨라지고 `×1`에서 원래 속도로 돌아옵니다.
- 판정: 완벽 / 빠름 / 느림 / 놓침. 놓치면 실패 (연습 모드에서는 계속 진행).

## 설정
- 싱크 보정: 소리와 판정이 어긋날 때 조절
- 연습 모드: 놓쳐도 계속
- 자동 재생: 구경하기

## 맵 만들기
메뉴의 **내 맵 → 새 맵 만들기**로 편집기를 열 수 있어요.

- 방향 버튼이나 키보드로 칸을 이어 붙여요: `W A S D` 상하좌우, `Q E Z C` 대각선, `Shift`+대각선은 셋잇단용 60° 방향.
- 선택한 칸에 회전 반전(`T`)과 속도(`1` ×0.5, `2` ×1, `3` ×1.5, `4` ×2)를 걸 수 있어요.
- 칸마다 앞 칸과의 박자 간격이 표시돼요 (½, ¾, 1, 1½ …).
- `[` `]`로 칸 선택, 칸을 눌러 선택, 끌어서 화면 이동, 휠로 확대.
- BPM과 스타일(12개 월드의 색과 음악)을 고를 수 있어요.
- **테스트**로 직접 해보고, **자동 재생**으로 리듬을 들어볼 수 있어요.
- **저장**하면 메뉴의 내 맵 목록에 남고 (브라우저에 저장), **공유 코드**로 친구와 맵을 주고받을 수 있어요.
